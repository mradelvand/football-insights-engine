Football Insights Engine — an AI match commentator you can trust
Replays a real Premier League match event by event. Code computes the facts, AI writes the words, code checks every word.
1 · The pipeline
01FETCH + VERIFY
StatsBomb open data, PL 2015/16 → data/raw (never committed) · SHA-256 + schema check · data version dv-…
02INGEST
Events → our format → replayed one by one at 20× speed · TV clock (64:49 → 65')
03INTERPRET
Live stats: possession, field tilt, PPDA, momentum, xG, Elo → fact cards → priority queue
THE ONLY AI STAGE
04EXPLAIN
Narrator agent writes wording with slots like {player_surname}; code fills the real values
✓ pass✗ reject
05VERIFIER
Plain-code checks: numbers, names, comparisons, bias words. Fail twice or > 1.2 s → template line
06RENDER + PERSONALIZE
Timed on-screen overlay with receipts · analyst or casual-fan wording
If you know monitoring telemetry → metrics → alert rules → alert message → validation → dashboard
