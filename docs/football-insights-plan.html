Football Insights Engine

A 7-week build (Oct 8 → Nov 22, 2026) that replays a real Premier League match (Leicester 3–1 Everton, 2016) one event at a time and puts short insights on screen, with every number, name and comparison checked before anyone sees it. An independent portfolio project inspired by the Microsoft × Premier League "Inside the Game" brief, not an official entry. Data: StatsBomb open data, Premier League 2015/16, not for commercial use.

How it works

Fetch→Ingest→Interpret→Explain→Render→Personalize

Design rule: code computes the facts → AI writes the wording with slots → code fills the values and checks every number, name and comparison. If the check fails twice or the AI takes over 1.2 s, a template line goes out.

Ground rules

  • Personal accounts only: no work tenants, laptops or credentials.
  • No API keys or secrets in code. Azure access uses DefaultAzureCredential (keyless) only.
  • StatsBomb open data only, credited with their logo. Raw and converted event files are never committed. Not for commercial use.
  • Season comparisons use only matches played before the replayed one.
  • Players are described only through facts in the card.
  • Test first for every metric. Never cut the metric tests, the verifier or the video.
  • Running behind? Cut in this order: French output → second agent → KQL logs → Azure deploy (demo locally instead).
