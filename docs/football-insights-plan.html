Football Insights Engine

A 7-week build (Oct 8 → Nov 22, 2026) that turns synthetic football match events into explainable live stats, AI-written insights and personalized recaps. It's an independent portfolio project inspired by the Microsoft × Premier League "Inside the Game" brief, not an official entry. All data is synthetic, and every club and player is fictional.

36 h 30required work
52required steps (+2 optional)
~7 hper week, with a 25% learning buffer
45 mindone so far

How it works

Simulate→Ingest→Interpret→Explain→Render→Personalize

Design rule: code computes the facts → AI writes the words → code checks the words against the facts. The verifier is plain Python, never a model.

Ground rules

  • Personal accounts only: no work tenants, laptops or credentials.
  • No API keys or secrets in code. Azure access uses DefaultAzureCredential (keyless) only.
  • Synthetic data with fictional clubs and players. No real player names, Premier League logos or copyrighted music.
  • Test first for every metric. Never cut the metric tests, the verifier or the video.
  • Running behind? Cut in this order: StatsBomb check → French output → second agent → KQL logs → Azure deploy (demo locally instead).
